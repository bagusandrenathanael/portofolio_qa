03 — CASE DETAIL
01

Redogg Food
Ordering Platform

WEB · MOBILE · FOOD

Menguji pengalaman pemesanan dari awal sampai selesai.

Platform memiliki aplikasi client, outlet, dan backoffice. Saya memetakan risiko pada pencarian menu, checkout, voucher, pembayaran, dan status pesanan.

Tantangan

Perubahan menu, harga, atau status outlet dapat memengaruhi pesanan pelanggan.

Peran QA

Menyepakati cakupan test dengan tim, mendokumentasikan temuan, dan mengotomasi alur regresi.

Uji alur berdasarkan peran dan risiko transaksi.

Exploratory testing membantu menemukan kasus batas, lalu automation menjaga jalur utama dari client hingga outlet.

Prioritas

Menu tidak tersedia, voucher, perubahan alamat, pembayaran gagal, dan status order.

Eksekusi

Manual testing untuk eksplorasi dan Playwright untuk alur web yang stabil dan berulang.

Temuan yang jelas untuk membantu tim merilis.

Test case dan bug report mencatat cakupan alur client, outlet, dan backoffice agar regresi bisa ditinjau bersama.

Artefak QA

Test case, bukti defect, dan automation checks.

Catatan

Tambahkan metrik dampak aktual bila datanya tersedia.
